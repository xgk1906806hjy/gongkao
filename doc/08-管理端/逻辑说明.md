# 08 · 管理端 — 逻辑说明

## 1. 模块职责

提供运营/管理员 REST API（无独立前端）：维护公告、题库、时政，查看采集失败。鉴权独立于微信用户 JWT。

## 2. 关键代码

| 路径 | 说明 |
|---|---|
| `server/internal/handler/router.go` | `/admin/*` 路由 |
| `server/internal/handler/handlers.go` | Admin handlers |
| `server/internal/service/auth.go` | `AdminLogin`、EnsureAdmin |
| `server/internal/service/practice.go` | 分类/题目 CRUD、JSON/CSV 导入 |
| `server/internal/service/announcement.go` / `affairs.go` | 内容维护 |

## 3. 主流程

1. `POST /admin/login` → admin JWT
2. 后续请求：`Authorization: Bearer <admin_token>`（middleware 校验 TokenAdmin）
3. 公告：列表（含未上架）、创建、更新（更新触发代办同步）
4. 题库：分类 upsert、题目 CRUD、`/questions/import`（JSON 或 CSV）
5. 时政：列表、创建、更新
6. `GET /admin/crawl-failures`：采集失败分页

## 4. 关键接口（摘要）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/admin/login` | 登录 |
| GET/POST/PATCH | `/admin/announcements...` | 公告 |
| GET/POST | `/admin/categories` | 分类 |
| GET/POST/PATCH/DELETE | `/admin/questions...` | 题目 |
| POST | `/admin/questions/import` | JSON 或 `text/csv` |
| GET/POST/PATCH | `/admin/affairs...` | 时政 |
| GET | `/admin/crawl-failures` | 失败记录 |

CSV 表头：`category,stem,answer_key,analysis,difficulty,tags,A,B,C,D`。

## 5. 边界与注意

- 本期**无可视化后台**，用脚本/HTTP 客户端调用即可
- 默认账号见 `ADMIN_BOOTSTRAP_*`，生产务必修改
- 管理接口应限制网络暴露面（反向代理鉴权/VPN）
