# 功能模块文档

本目录按**业务功能顺序**拆分模块说明，与根目录 `docs/`（PRD / 开发方案 / API / 项目总览）互补：

- `docs/`：产品与工程总览
- `doc/`：按模块沉淀的**逻辑说明**与**变动记录**

## 模块顺序

| 序号 | 目录 | 说明 |
|---|---|---|
| 01 | [01-登录鉴权](./01-登录鉴权/) | 微信登录、JWT、用户资料 |
| 02 | [02-考试公告](./02-考试公告/) | 公告列表/详情/筛选/上架 |
| 03 | [03-我的考试与代办](./03-我的考试与代办/) | 加入考试、代办生成与状态 |
| 04 | [04-订阅与提醒](./04-订阅与提醒/) | 订阅授权、Worker 推送 |
| 05 | [05-刷题](./05-刷题/) | 练习、判分、错题本、统计 |
| 06 | [06-时政](./06-时政/) | 时政列表、收藏、阅读 |
| 07 | [07-内容采集](./07-内容采集/) | 外网公告/时政采集插件 |
| 08 | [08-管理端](./08-管理端/) | Admin API、导题、失败查询 |
| 09 | [09-AI分析](./09-AI分析/) | 简历选岗、复习计划、备考问答 |

每个模块目录固定包含：

1. `逻辑说明.md` — 职责、流程、关键接口/表、边界
2. `变动记录.md` — 变更履历表（日期、摘要、影响范围、提交）

新增功能或较大改动时，请同步更新对应模块的两份文档。
