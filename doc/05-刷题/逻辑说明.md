# 05 · 刷题 — 逻辑说明

## 1. 模块职责

提供题库分类练习、交卷判分、错题本与个人统计，支撑备考刷题路径。

## 2. 关键代码

| 路径 | 说明 |
|---|---|
| `server/internal/service/practice.go` | 会话、check、交卷、错题、统计、导入/Admin CRUD |
| `miniapp/pages/practice/*` | 分类入口、答题、结果 |
| `miniapp/pages/mine/wrong/*` | 错题本与再练 |

## 3. 主流程

1. `GET /questions/categories` 展示分类
2. `POST /practice/sessions`：
   - `mode`：`sequential` / `random` / `wrong`（错题再练）
   - `show_analysis`：默认 true，控制是否允许单题揭示解析
   - 下发题目时**隐藏** `answer_key` 与 `analysis`
3. 作答中：`POST /practice/check` → 返回对错、正确答案、解析
4. `POST /practice/submit` → 判分、写 `user_answers`、错题入库、结束会话
5. 错题本：`GET/DELETE /me/wrong-questions...`；再练走 `mode=wrong`
6. 统计：`GET /me/practice/stats`（累计、正确率、近 7 日）

## 4. 关键接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/questions/categories` | 分类 |
| POST | `/practice/sessions` | 开始练习 |
| POST | `/practice/check` | 单题揭示 |
| POST | `/practice/submit` | 交卷 |
| GET/DELETE | `/me/wrong-questions...` | 错题本 |
| GET | `/me/practice/stats` | 统计 |

管理端导题 / CRUD 见模块 08。

## 5. 数据

`question_categories`、`questions`、`question_options`、`practice_sessions`、`user_answers`、`wrong_questions`。

## 6. 边界与注意

- 空题库时启动种子样题（`SeedIfEmpty`）
- 按考点筛选为 P1，尚未实现
- 交卷前是否显示解析由 `show_analysis` 控制
