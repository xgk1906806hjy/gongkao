# 07 · 内容采集 — 逻辑说明

## 1. 模块职责

以可插拔 Source 从公开网络拉取公告与时政，写入业务表；失败记入 `crawl_failures`。由 Worker 定时调度，亦可手动 `crawlonce`。

## 2. 关键代码

| 路径 | 说明 |
|---|---|
| `server/internal/crawler/crawler.go` | Runner、源注册、种子降级 |
| `server/internal/crawler/cpta.go` | 中国人事考试网 |
| `server/internal/crawler/gov_zhengce.go` | 政府网最新政策 JSON + 招考关键词 |
| `server/internal/crawler/rss.go` | 通用 RSS 时政 |
| `server/internal/crawler/httputil.go` | HTTP 拉取工具 |
| `server/cmd/worker/main.go` | 约每 30 分钟 `RunOnce` |
| `server/cmd/crawlonce/main.go` | 本地一次性采集 |

## 3. 主流程

1. `NewRunner` 注册内置源 + 环境变量额外 RSS
2. 各 Source `Fetch`：拉取 → 解析 → `UpsertFromCrawl`
3. 单源失败：记日志 + `crawl_failures`，不中断其他源
4. `CRAWLER_SEED_FALLBACK=true` 且尚无外网数据时，写入演示种子

### 内置源

| 名称 | 产出 |
|---|---|
| `cpta` | 公告（notice/examNotice 等）+ 时政链接 |
| `gov-zhengce` | 招考相关政策/公告（关键词过滤） |
| `xinhua-politics` / `people-politics` / `xinhua-legal` | 时政 RSS |
| `seed-*` | 仅降级演示 |

## 4. 配置

- `CRAWLER_ENABLED`：Worker 是否调度
- `CRAWLER_SEED_FALLBACK`：无外网数据时是否种子
- `CRAWLER_AFFAIRS_RSS_URL` / `CRAWLER_AFFAIRS_RSS_URLS`：追加时政 RSS

## 5. 边界与注意

- 合规：摘要 + 原文链接，避免全站镜像
- 站点改版会导致解析失败，需看失败表与日志
- 政府网关键词近期可能命中少，公告以人事考试网为主
