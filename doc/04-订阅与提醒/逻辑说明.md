# 04 · 订阅与提醒 — 逻辑说明

## 1. 模块职责

管理用户微信订阅消息授权，并由 Worker 在代办到期前发送提醒（可选每日时政推送）。

## 2. 关键代码

| 路径 | 说明 |
|---|---|
| `server/internal/service/subscribe.go` | 订阅偏好读写与 accept 校验 |
| `server/internal/service/reminder.go` | 到期扫描、发送、重试、skip |
| `server/internal/service/affairs_push.go` | 可选每日时政推送 |
| `server/cmd/worker/main.go` | 每分钟提醒；可选 08:00 时政 |
| `server/internal/wx/client.go` | `SendSubscribe`（MOCK 打日志） |
| `miniapp/pages/mine/subscribe/*` | 订阅设置页 |
| `miniapp/services/auth.js` | `requestSubscribeMessage` + 上报 prefs |

## 3. 主流程

### 3.1 授权

1. 客户端拉取 `GET /config/client` 获取模板 ID（MOCK 下有占位 ID）
2. `wx.requestSubscribeMessage`
3. `POST /me/subscribe-prefs` 上报 `todo` / `affairs` 为 `accept` 或 `reject`

### 3.2 代办提醒

1. Worker 每分钟：`ZRANGEBYSCORE todo:remind` 或 DB 扫描 `remind_at<=now`
2. 校验代办 pending + 用户对 `todo` 已 accept
3. 无模板且非 MOCK → skipped；有授权则调用微信发送
4. 成功 → `sent`；失败 → 重试（默认 <3）后 `failed`

### 3.3 每日时政（可选）

`AFFAIRS_DAILY_PUSH_ENABLED=true` 时，对 `affairs=accept` 用户推送最新一篇时政摘要。

## 4. 关键接口 / 配置

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/config/client` | 下发模板 ID、`wx_mock` |
| GET/POST | `/me/subscribe-prefs` | 查询/上报授权 |

环境变量：`WX_SUBSCRIBE_TEMPLATE_TODO`、`WX_SUBSCRIBE_TEMPLATE_AFFAIRS`、`WX_MOCK`、`AFFAIRS_DAILY_PUSH_ENABLED`。

## 5. 数据

`user_subscribe_prefs`：user_id + kind（todo/affairs）唯一，status=accept|reject。

代办侧 `remind_status`：pending / sent / skipped / failed。

## 6. 边界与注意

- 未授权**不推送**，代办列表仍可高亮即将到期项
- 真机需正式 AppID、模板审核、Worker 常驻
- 微信订阅多为一次性授权，需在关键节点反复引导
