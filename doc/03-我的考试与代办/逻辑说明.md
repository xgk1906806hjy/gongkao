# 03 · 我的考试与代办 — 逻辑说明

## 1. 模块职责

用户将公告加入「我的考试」后，按公告时间线自动生成代办，并支持完成/关闭与列表展示（倒计时、即将到期高亮）。

## 2. 关键代码

| 路径 | 说明 |
|---|---|
| `server/internal/service/exam_todo.go` | 加入/离开、代办生成与 PATCH、改期同步、提醒入队 |
| `miniapp/pages/mine/exams/*` | 我的考试列表 |
| `miniapp/pages/mine/todos/*` | 代办分组列表、完成/关闭 |
| `miniapp/pages/announcement/detail.js` | 加入考试并引导订阅 |

## 3. 主流程

### 3.1 加入考试（幂等）

1. `POST /me/exams` `{ announcement_id }`
2. 已存在则只补偿生成/刷新代办；否则创建 `user_exams`
3. `generateTodos` 规则：
   - 报名：优先 `register_end`，否则 `register_start`
   - 确认：优先 `confirm_end`，否则 `confirm_start`
   - 考试：`exam_at`
4. `remind_at = due_at - 10m`，pending 代办写入 Redis ZSET `todo:remind`

### 3.2 离开考试

- 未完成代办标记 `cancelled`，提醒 `skipped`，并从 ZSET 移除
- 删除 `user_exams` 关联

### 3.3 代办状态

- `PATCH /me/todos/:id`：`done` / `cancelled` / `pending`
- 完成或关闭时跳过后续提醒

### 3.4 公告改期同步

`SyncTodosForAnnouncement`：对该公告下所有已加入用户，刷新尚未发送成功的 pending 代办时间。

## 4. 关键接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST | `/me/exams` | 列表 / 加入 |
| DELETE | `/me/exams/:announcementId` | 离开 |
| GET | `/me/todos` | 按公告分组 |
| PATCH | `/me/todos/:id` | 改状态 |

## 5. 数据

- `user_exams`：user_id + announcement_id 唯一
- `todos`：type、due_at、remind_at、status、remind_status、retry

## 6. 边界与注意

- 时间字段为空则不生成对应代办节点
- 提醒实际发送逻辑在模块 04；本模块只负责生成与入队
- 列表 UI：24h 内即将到期高亮、倒计时文案
