# 01 · 登录鉴权 — 逻辑说明

## 1. 模块职责

负责考生用户与管理员的身份认证、会话维持与基础资料维护。

- C 端：微信小程序登录 → JWT（access + refresh）
- 管理端：用户名密码登录 → admin 类型 JWT
- 用户资料：昵称、头像更新；`session_key` 仅存服务端

## 2. 关键代码

| 路径 | 说明 |
|---|---|
| `server/internal/service/auth.go` | 登录、刷新、资料、管理员引导 |
| `server/internal/wx/client.go` | `code2session`、access_token（支持 `WX_MOCK`） |
| `server/internal/middleware/auth.go` | Bearer 校验、token 类型区分 |
| `server/internal/pkg/jwt.go` | JWT 签发与解析 |
| `miniapp/services/auth.js` | `ensureLogin`、订阅相关封装 |
| `miniapp/services/api.js` | 带 token 请求、401 自动 refresh |
| `miniapp/pages/mine/mine.*` | 登录入口、头像昵称编辑 |

## 3. 主流程

### 3.1 微信登录

1. 小程序调用 `wx.login` 获取 `code`
2. `POST /api/v1/auth/wechat` 提交 `code`（可选 nickname/avatar）
3. 后端 `code2session`（MOCK 时用 `mock_<code>` 作为 openid）
4. 按 openid upsert `users`，`session_key` AES 加密入库
5. 返回 `access_token`、`refresh_token`、`user`

### 3.2 访问受保护资源

- Header：`Authorization: Bearer <access>`
- access 过期：客户端 `POST /auth/refresh`，失败则清本地 token 并重新登录

### 3.3 管理员

- `POST /api/v1/admin/login` → bcrypt 校验 → admin JWT
- 首次启动按 `ADMIN_BOOTSTRAP_*` 引导创建管理员

## 4. 关键接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/auth/wechat` | 微信登录 |
| POST | `/auth/refresh` | 刷新双 token |
| GET | `/me` | 当前用户 |
| PATCH | `/me` | 更新昵称/头像 |
| POST | `/admin/login` | 管理员登录 |

## 5. 数据

- `users`：openid、unionid、nickname、avatar_url、session_key_enc
- `admin_users`：username、password_hash、role

## 6. 边界与注意

- `WX_MOCK=true` 时任意 code 可登录，仅用于本地
- `session_key` 不得下发客户端
- refresh 黑名单 / 登出作废尚未实现（P1）
