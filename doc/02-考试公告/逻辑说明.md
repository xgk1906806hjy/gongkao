# 02 · 考试公告 — 逻辑说明

## 1. 模块职责

聚合公务员（`civil`）与事业单位（`institution`）招考公告，供 C 端浏览筛选，并为「我的考试」提供数据源。

## 2. 关键代码

| 路径 | 说明 |
|---|---|
| `server/internal/service/announcement.go` | 列表筛选、详情、CRUD、采集 upsert |
| `server/internal/handler/handlers.go` | C 端与 Admin 公告接口 |
| `miniapp/pages/home/*` | 公告列表与筛选 UI |
| `miniapp/pages/announcement/detail.*` | 详情、加入考试入口 |

## 3. 主流程

1. C 端仅可见 `status=published` 的公告
2. 列表支持：`type`、`region`、`keyword`、`published_from` / `published_to`、分页
3. 列表卡片展示关键节点摘要（报名截止/开始、确认、考试时间等）
4. 详情展示摘要/正文、来源链接、时间线字段
5. 内容来源：采集模块写入 + 管理端人工维护

## 4. 关键接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/announcements` | 列表（筛选+分页） |
| GET | `/announcements/:id` | 详情 |
| GET/POST/PATCH | `/admin/announcements...` | 管理端维护 |

管理端更新时间线后，会触发代办同步（见模块 03）。

## 5. 数据

`announcements`：type、title、region、source、source_id、source_url、summary、content、报名/确认/考试时间、published_at、status。

去重键：`source + source_id`（采集 upsert）。

## 6. 边界与注意

- 采集得到的时间线字段可能不完整，需人工补录
- 下架（offline）后 C 端不可见，已加入考试的历史数据策略见代办模块
