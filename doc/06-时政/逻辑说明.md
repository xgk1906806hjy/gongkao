# 06 · 时政 — 逻辑说明

## 1. 模块职责

提供时政文章浏览、标签/关键词筛选、详情阅读记录与收藏，内容主要来自采集模块的 RSS/站点摘要。

## 2. 关键代码

| 路径 | 说明 |
|---|---|
| `server/internal/service/affairs.go` | 列表、详情、收藏、采集 upsert、种子 |
| `miniapp/pages/affairs/*` | 列表（标签 chips）、详情 |
| `miniapp/pages/mine/favorites/*` | 我的收藏 |

## 3. 主流程

1. `GET /affairs?tag=&keyword=&page=` 分页列表（仅已上架）
2. `GET /affairs/:id`：OptionalAuth；登录用户写阅读记录
3. 收藏：`POST/DELETE /me/affairs/favorites...`，列表 `GET /me/affairs/favorites`
4. 内容写入：采集 upsert（按 `source_url` 去重）或管理端发布

每日订阅推送逻辑见模块 04（开关默认关闭）。

## 4. 关键接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/affairs` | 列表 |
| GET | `/affairs/:id` | 详情 |
| GET/POST/DELETE | `/me/affairs/favorites...` | 收藏 |
| GET/POST/PATCH | `/admin/affairs...` | 管理维护 |

## 5. 数据

`affairs_articles`、`affairs_favorites`、`affairs_reads`。

## 6. 边界与注意

- 正文多为摘要 + 原文链接，非全文镜像
- 标签来自采集字段或运营配置；小程序端预置常用筛选 chips
